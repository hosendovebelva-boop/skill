# 六级 + 雅思备考驱动器 (english-drill)

## 学习者基线（判断难度和给建议时以此为准）

CET-4 444 分。口语能日常交流，缺的是词汇宽度和反应速度。**部分词看得懂但不会读**，这是首要短板，它同时压住听力和口语。主动词汇量约 3500–4000，目标 7000–8000。

不要默认他是零基础，也不要默认他能听懂原速学术讲座。

## 产出去向

skill 生成的内容写进这四个目录，目录不存在就建：

| 目录 | 内容 | 文件名 |
|---|---|---|
| `13. 英文/生词本/` | 认识但没听出来的词、口语里卡住想不起来的词 | `YYYY-MM.md`，按月一个文件，追加 |
| `13. 英文/错题本/` | 做错的题 + 错因归类 | `YYYY-MM.md`，同上 |
| `13. 英文/写作/` | 作文原稿 + 批改 + 改后稿 | `YYYY-MM-DD-任务类型-话题.md` |
| `13. 英文/口语/` | 话题卡、自答要点、反馈 | `Part1-话题.md` / `Part2-话题.md` |

生词本和错题本的条目要能直接变成 Anki 卡片，所以每条至少写清：词/题、错在哪、正确的是什么。

## 每日任务的固定结构

总 2–2.5 小时，四块。时间紧砍 C，A、B、D 任何情况下不砍。

| 块 | 时长 | 内容 |
|---|---|---|
| A 词汇 | 25 min | Anki，早上清空当日队列 |
| B 精听 | 40 min | 听写 + 跟读六步流程 |
| C 主项 | 30–50 min | 按阶段轮换 |
| D 开口 | 25 min | shadowing 15 + 自问自答录音 10 |

出「今日任务」时给具体到文件的指令，不要给「练听力」这种。例：「B 块：剑 8 Test 2 Section 3，音频 `【08】剑桥雅思8听力音频/Test2/Test2.Section3.mp3`，前 2 分钟」。

## 硬性约束

**批改作文**：按 TR / CC / LR / GRA 四项分开打分，每项各给**一条能立刻改的具体修改**，附原句和改后句。不写总评，不写鼓励的话。先查时态和主谓一致，这两类错误存在就直接说明分数上不了 6。

**不给模板。** 不提供可以整段背诵的答案、开头句、万能句。2026 年起雅思口语全程录音配 AI 初审，模板化表达的风险比以前高。要给的是可以自由重组的搭配和句式骨架。

**精听复盘**：漏听的词必须分两堆，不认识的进 Anki，认识但没听出来的进生词本。后者才是听力提分的来源，不要混在一起。判断原因时要具体到是连读、弱读、闪音还是读音记错了。

**口语反馈**：只给三样，卡在哪、哪个词想不起来、哪句语法错了。不评价内容好不好。

**做题量的原则**：分析时间不少于做题时间。用户说「多做几套」时提醒这一条。

## 重新生成牌组

```bash
cd "13. 英文/工具"
python3 vocab2anki.py --fetch-audio --workers 12
```

产出 `out/vocab.tsv`（4919 卡，Basic 牌型，带导入指令头）和 `out/media/`（4851 个 mp3）。断点续传，重跑只补缺的。牌组分三层：`英语::1-六级雅思共有`(1481)、`英语::2-六级独有`(1492)、`英语::3-雅思独有`(1946)，行序即学习顺序。

Anki 设置：新卡六级期 20/天、雅思期 12/天，复习上限 9999（设上限会积压），desired retention 0.90，学习步骤单步 `10m`。

标签 `有真题例句` 的 1370 词在六级考前一个月单独筛出来过一遍。macOS 自带的 BSD grep 不支持 `-P`，用 awk 按列筛：

```bash
awk -F'\t' '$3 ~ /有真题例句/' out/vocab.tsv | wc -l
```

在 Anki 里直接搜 `tag:有真题例句` 更方便。
