## 执行流程

### 第一步：确定题目信息

从用户输入中提取：
1. **题号**（如 260）
2. **题目名称**（如 只出现一次的数字 III）
3. **难度**（简单/中等/困难）
4. **所属算法分类**（如 位运算、动态规划、双指针等）
5. **题目描述**（用户提供或从用户消息中提取）
6. **题解代码**（用户提供）

### 第二步：确定目录位置

1. 根据算法分类，查找 `5.2 算法` 中对应的章节编号
2. 按映射规则确定 `5.3 力扣` 下的目标目录
3. 检查目录是否存在：
   - **存在** → 直接使用
   - **不存在** → 创建目录

```bash
# 检查目录
ls "D:\obsidian\C++\5.算法\5.3 力扣\5.3.X 目录名\"

# 如果不存在，创建
mkdir "D:\obsidian\C++\5.算法\5.3 力扣\5.3.X 目录名"
```

### 第三步：创建 SVG 图解（推荐）

为题解创建辅助理解的 SVG 图，存放在 `D:\obsidian\C++\图片\SVG\` 下。

**命名规则**：`lc_{题号}_{简短描述}.svg`，如 `lc_260_xor_split.svg`。

SVG 必须遵循仓库设计规范：
- 背景色：`rgb(245, 244, 237)`
- 字体：`Microsoft YaHei`, `Noto Sans CJK SC`
- 箭头：小号空心箭头（`fill="none"` + `stroke`）
- 配色柔和，与现有 SVG 风格一致

### 第四步：创建题解笔记

使用 Write 工具在目标目录下创建 `{题号}. {题目名称}.md`。

### 第五步：更新练习分配表

找到 `5.2 算法` 中对应章节笔记的 `## 截图题目练习分配` 表格，在对应题目的「引用」列添加 wiki-link：

```markdown
[[5.算法/5.3 力扣/5.3.X 目录名/{题号}. {题目名称}|{题号}. {题目名称}]]
```

### 模板使用说明

- 章节编号（一、二、三...）**灵活调整**，根据题目复杂度增减
- 简单题可以省略"正确性证明"和"对比"章节
- 复杂题应增加"优化过程"或"多解法对比"章节
- **每段代码都必须有讲解**，不能只堆砌代码
- 图解过程章节**强烈推荐**配 SVG，但不强制
