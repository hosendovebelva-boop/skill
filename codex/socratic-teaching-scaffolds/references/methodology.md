# Advanced Socratic Teaching Methodology

Read this for complex topics, persistent misconceptions, or multi-session learning.

## Deep Diagnostic Techniques

- Concept mapping: ask the learner to describe how related ideas connect.
- Predict-observe-explain: ask for a prediction, reveal the real behavior, then ask why they differ.
- Analogical probe: offer an analogy and ask where it matches and where it breaks.
- Backward chaining: list prerequisites for the target concept and start at the first missing one.

## Misconception Types

| Type | Revealing Question | Teaching Move |
| --- | --- | --- |
| Causal reversal | Does A cause B or B cause A? | Separate direction from correlation |
| False dichotomy | Must it be X or Y? | Introduce both/neither/multiple cases |
| Overgeneralization | Does this always hold? | Test edge cases |
| Undergeneralization | Where else might this apply? | Transfer to broader contexts |
| Confused levels | Is this about the high-level behavior or low-level mechanism? | Separate abstraction layers |

## Branching Question Trees

Prepare branches:

```text
Q1 diagnostic
|-- correct -> advance
|-- misconception -> correction sequence -> verify -> advance
|-- stuck -> scaffold -> retry
```

Do not force a prewritten ladder when the learner's response reveals a better path.

## Persistent Misconception Protocol

1. Acknowledge without judgment.
2. Ask for an explicit prediction based on the misconception.
3. Show or explain a contradiction.
4. Guide the correct model through questions.
5. Reinforce with 2-3 new examples.
6. Recheck later in a different context.

For deep misconceptions, build the correct model from scratch before dismantling the old one.

## Cognitive Apprenticeship

Use this progression:

1. Modeling: demonstrate with thinking aloud.
2. Coaching: learner tries while teacher guides.
3. Scaffolding: provide temporary structure.
4. Articulation: learner explains reasoning.
5. Reflection: compare strategies and limits.
6. Exploration: learner solves novel problems independently.

## Transfer Validation

- Near transfer: same domain, similar problem.
- Modified transfer: same domain, adapted problem.
- Far transfer: different domain with the same structure.
- Creative transfer: design or synthesize something new.

True understanding should survive at least near transfer and a learner explanation in their own words.
