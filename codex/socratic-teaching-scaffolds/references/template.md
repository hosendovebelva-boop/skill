# Socratic Teaching Session Template

Use this template when the user wants a structured teaching session, lesson plan, or reusable self-study scaffold.

## Session Checklist

```markdown
Teaching Session Progress:
- [ ] Step 1: Diagnose current understanding
- [ ] Step 2: Build question ladder
- [ ] Step 3: Execute teaching session
- [ ] Step 4: Fade scaffolding
- [ ] Step 5: Validate understanding
```

## 1. Diagnostic Phase

Ask 3-5 questions before teaching:

1. What do you already know about the topic?
2. Can you give an example of a related idea?
3. What do you think the key term means?
4. How would you approach a simple problem using it?
5. What do you predict will happen in a misconception-revealing case?

Record the learner goal, current experience, knowledge gaps, likely misconceptions, and starting scaffolding level.

## 2. Question Ladder Design

Build from concrete to abstract:

1. Concrete foundation: familiar analogy or example.
2. Pattern recognition: questions that help the learner notice structure.
3. Formalization: introduce vocabulary after the pattern is visible.
4. Edge cases: ask where the idea breaks or needs qualification.
5. Transfer: apply the idea in a new context.

Aim for 8-10 purposeful questions for a full lesson plan. In live chat, ask only the next useful question and wait.

## 3. Teaching Loop

For each ladder step:

1. Ask the question clearly.
2. Give thinking time.
3. Interpret the response:
   - Correct: confirm the reasoning and advance.
   - Partial: ask a follow-up.
   - Misconception: use prediction-observation-explanation.
   - Stuck: provide a scaffold.
4. Ask the learner to restate the insight in their own words.

## 4. Scaffolding Fading

Track support per concept:

| Concept | Initial Level | Current Level | Ready For Independence |
| --- | --- | --- | --- |
| [Concept] | Level 4 | Level 3 | [ ] |

Fade when the learner succeeds. Increase support when they are stuck for too long or show frustration.

## 5. Validation

Use at least one:

- Explanation test: explain to a child, peer, or expert.
- Application test: solve a novel problem.
- Teaching test: explain how to teach it and what would confuse learners.
- Misconception check: revisit the original wrong model in a new case.

End with a summary, one concrete practice task, and a success criterion.
